# CASPER 매뉴얼 연결 이미지 표시

## 변경 내용

질문 → 기존 E5 본문 검색 → 검색된 청크의 이미지 연결 조회 → 본문·이미지 설명·실제 그림으로 답변 생성 → 답변과 연결 이미지 표시

- 이미지의 원본 PDF 페이지와 연결된 검색 근거 번호를 표시합니다.
- 같은 이미지가 여러 근거에 연결돼도 답변의 그림 목록에는 한 번만 표시합니다.
- 각 근거당 최대 3개, 한 답변당 서로 다른 이미지 최대 12개를 표시합니다.
- 이미지 설명과 OCR은 자동 생성 자료입니다. 본문과 충돌하면 본문을 우선하도록 답변 지침에 명시했습니다.
- 이미지 조회가 실패해도 본문 답변을 계속 제공하고, 이미지 조회 실패 안내를 표시합니다.
- 실제 그림은 Supabase의 공개 이미지 URL을 Responses API의 `input_image`로 전달합니다. URL을 단순 텍스트로 주는 것이 아니라 이미지 입력 항목으로 첨부합니다.
- 답변 모델에 보내는 실제 그림은 최대 6개입니다. 상위 검색 근거에서 하나씩 먼저 선택하고, 같은 이미지는 중복해서 보내지 않습니다. 모든 표시 이미지가 모델에 전달되는 것은 아닙니다.
- 전달한 그림에는 화면에 ‘그림 1’ 등의 번호를 표시합니다. 답변에서도 같은 그림 번호와 본문 근거 번호를 사용하도록 지시했습니다.
- 이미지 URL 다운로드·형식 등의 400 오류가 발생하면, 실제 그림 없이 본문과 이미지 설명으로 한 번 재요청하고 화면에 안내합니다. 인증·요금·일반 서버 오류는 이 재요청 대상이 아닙니다.
- 이미지 자체를 벡터 검색하는 기능은 추가하지 않았습니다. 검색 순위는 기존 본문 임베딩으로 정하고, 확정된 청크·이미지 연결을 사용합니다.
- 실제 그림을 보내므로 이미지 입력에 따른 API 사용료와 처리 시간이 추가될 수 있습니다.

구현 형식 참고: [OpenAI 공식 이미지 입력 안내](https://developers.openai.com/api/docs/guides/images-vision)
