# CASPER 매뉴얼 연결 이미지 표시

## 변경 내용

질문 → 기존 E5 본문 검색 → 검색된 청크의 이미지 연결 조회 → 본문·이미지 설명으로 답변 생성 → 답변과 연결 이미지 표시

- 이미지의 원본 PDF 페이지와 연결된 검색 근거 번호를 표시합니다.
- 같은 이미지가 여러 근거에 연결돼도 답변의 그림 목록에는 한 번만 표시합니다.
- 각 근거당 최대 3개, 한 답변당 서로 다른 이미지 최대 12개를 표시합니다.
- 이미지 설명과 OCR은 자동 생성 자료입니다. 본문과 충돌하면 본문을 우선하도록 답변 지침에 명시했습니다.
- 이미지 조회가 실패해도 본문 답변을 계속 제공하고, 이미지 조회 실패 안내를 표시합니다.
- 실제 이미지 픽셀을 답변 모델에 보내거나 이미지 자체를 벡터 검색하는 기능은 이번 변경에 포함되지 않습니다. 확정된 청크·이미지 연결을 사용합니다.
